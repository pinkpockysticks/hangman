# Hangman

A command line Hangman game built in Java, designed to practise object-oriented programming, input validation and game state management.

## About

Hangman is a two player word guessing game. Player 1 enters a word or
phrase, optionally provides a category or hint, and Player 2 attempts
to guess the phrase one letter at a time.

The game allows up to six incorrect guesses before Player 2 loses.

## How to Play

1. Select whether to start a new game or continue a saved game. 
2. Enter the names of both players. 
3. Player 1 enters a word or phrase. 
4. Player 1 can optionally provide a category or hint. 
5. The phrase is displayed with hidden letters. 
6. Player 2 guesses letters one at a time. 
7. An incorrect guess counts towards the six guess limit. 
8. Player 2 wins by revealing the complete phrase before reaching six incorrect guesses.
